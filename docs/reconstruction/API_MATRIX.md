## 2. Extended & Post-Pilot Modules (Hardened at Middleware, Ownership & Consent Boundaries)

| Domain / Base Path | Disposition | Auth / RBAC Policy Applied | Consent, PII & Isolation Notes |
| --- | --- | --- | --- |
| **Analytics** (`/api/analytics`) | Telemetry ingestion & reporting | `POST /track`, `/events`, `/game`, `/learning` require `authenticateToken`; `GET /engagement`, `/recent` require `admin` | Derives `user_id`/`student_id` from `req.user.userId`; scrubs raw PII (phones, personal emails, Telegram handles) via `dataPipelineValidator.ts` before persistence; 0 writes when `!canCollectAnalytics` |
| **AI & Memory v1** (`/api/ai`) | Post-pilot / gated | Public read-only `/knowledge*`; all student chat/recommend/insight/feedback/memory routes require `authenticateToken` + `resolveAuthorizedStudentId` | `StudentAIMemoryService` & `aiRecommendationService` do not persist or fabricate data when `!canUseAIMemory` |
| **AI OS v2** (`/api/ai-os`) | Post-pilot / gated | `GET /agents`, `GET /tutor/concept` public; student chat/memory/plans require `authenticateToken` + `resolveAuthorizedStudentId`; `/knowledge/pipeline`, `/safety/test`, `/analytics/metrics` require `admin` | Per-student scoped milestone PKs + IDOR-safe `toggleMilestone`; audit snippets redact minor PII |
| **Research** (`/api/research`) | Post-pilot / gated | `GET /experiments*` public study metadata; `POST /experiments/:id/join` requires `authenticateToken` + `canIncludeInResearch`; `POST /experiments`, `GET /experiments/:id/report`, `GET /anonymized-dataset` require `admin` | Live SQLite queries filtered strictly to `privacyService.getResearchEligibleStudents()`; unified experiment table visibility; zero `any` types |
| **Data Platform** (`/api/data-platform`) | Mixed (Lakehouse public metadata; student & pipeline gated) | `/student-dossier`, `/governance*`, `/ml/*` require `authenticateToken` + `resolveAuthorizedStudentId`; `/improvement-flywheel`, `/collection-matrix`, `/ai-pipeline/*` require `admin` | Governance status reads strictly from `PrivacyService`; flywheel writes require `canCollectAnalytics` |
| **Student Intelligence** (`/api/student/profile`) | Post-pilot / gated | `authenticateToken` + `resolveAuthorizedStudentId` on `/intelligence*`, `/recalculate`, `/ai-context` | Unconsented students return `engagementScore: 0` with zero DB writes |
| **Learning & STEM Labs** (`/api/learning`, `/api/learning-science`) | Post-pilot / gated | Catalog public; all student labs/paths/mastery require `authenticateToken` + `resolveAuthorizedStudentId`; cohort reports/telemetry require `admin` | Viewing logs & research telemetry gated by `canCollectAnalytics` |
| **Avatar World** (`/api/avatar-world`) | Post-pilot / gated | All routes require `authenticateToken`; student derived strictly from `req.user.userId` | Mass-assignment stripped (`level`/`merit_points` immutable via profile edit); locked inventory item placement rejected (`403`); telemetry consent-gated |
| **Community & Mentoring** (`/api/community`) | Post-pilot / gated | Public directories strip raw `user_id`; writes & student-owned routes require `authenticateToken` + `resolveAuthorizedStudentId`; moderation queue requires `admin` | Forced `member` role on join, prohibited keyword filtering on both `title` and `content`, cross-post `accept-answer` rejected (`404`), schema-compliant mentor `session_type` |
| **Knowledge / Digital World / Platform** (`/api/knowledge`, `/api/digital-world`, `/api/platform`) | Post-pilot / gated | Writes & companion chat require `authenticateToken`; verify/rag-sync/audit-logs/notifications/ecosystem/monitoring require `admin` | Unpublished drafts hidden from non-admins; server-derived author IDs; deduped votes; mobile device ownership enforced (`403` on hijack); companion chat safety & consent gated |
