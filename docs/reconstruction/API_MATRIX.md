# CDES Student Instructor V1.2.0 — Verified API & Feature Disposition Matrix

> Reflects post-reconstruction verified server behavior in `server/app.ts` and mounted routers/controllers.

## 1. Core Pilot & Platform Routes

| Domain / Base Path | Key Endpoints | Auth / Role Policy | Ownership & Consent Enforcement | Data Source / Persistence | Verification Status |
| --- | --- | --- | --- | --- | --- |
| **Health & Readiness** (`/api/health`) | `GET /api/health` | Public | None (read-only status probe) | Live SQLite `SELECT 1`, `PRAGMA journal_mode/foreign_keys/quick_check`, `schema_version`, `readinessState`; returns `200` ready or `503` on migration/integrity failure | Tested HTTP `200` & `503` (`startupAndMigrations.test.ts`, clean-dir prod smoke) |
| **Auth & Session** (`/api/auth`) | `GET /csrf`, `GET /session`, `POST /register`, `POST /login`, `POST /logout`, `GET /me` | Public (`/csrf`, `/session`, `/register`, `/login`, `/logout`); `authenticateToken` (`/me`) | Sets HttpOnly `cdes_jwt` + HttpOnly `cdes_csrf_secret`; returns session-bound `X-CSRF-Token` header & `csrfToken` JSON; registration seeds pending/unverified privacy consents (`allow_*=0`) transactionally | SQLite `users`, `student_profiles`, `education_history`, `student_privacy_consents`, `cdes_data_governance_consents` | Tested HTTP E2E (`authOwnershipConsent.test.ts`, clean-dir prod smoke) |
| **User Profile & Education** (`/api/users`) | `GET /profile`, `PUT /profile`, `POST /education`, `DELETE /education/:id` | `authenticateToken` (all roles) | Strictly scoped to `req.user.userId`; strips body `id`/`user_id`; deletes require profile ownership | SQLite `student_profiles`, `education_history` | Tested HTTP E2E + reload/restart persistence + cross-student isolation |
| **Privacy & Consent** (`/api/privacy`) | `GET /consent`, `POST /consent`, `POST /parent-verify`, `POST /parent-verify/:studentId/approve` | `authenticateToken`; `:studentId/approve` requires `admin` | Syncs `student_privacy_consents` + `cdes_data_governance_consents`; non-admins cannot self-verify parental approval; minors without verified guardian remain blocked (`allow_*=0`); `withdrawAll` sets `withdrawn` & `withdrawn_at` | SQLite `student_privacy_consents`, `cdes_data_governance_consents` | Tested HTTP E2E (`authOwnershipConsent.test.ts`) |
| **Scholarships** (`/api/scholarships`) | `GET /`, `/search`, `/featured`, `/metrics`, `/stats`, `/:id`; `POST /match`; `POST /submit`, `GET /submissions/mine`; `POST /report`, `/report-error`; Admin: `GET /submissions*`, `PUT/POST /submissions/:id*`, `/admin/*`, `POST/PUT/DELETE /:id*`, `POST /check-updates`, `POST /ai-extract` | Public reads (`GET`); `submit`/`submissions/mine` require `organization` or `admin`; error reports require `authenticateToken`; moderation/CRUD/admin stats/update check require `admin` | Search-term logging disabled; `submit` derives `submitted_by_user_id` from `req.user`; `reviewSubmission` runs in `BEGIN IMMEDIATE` transaction (idempotent on repeat, `409` on conflict, never publishes rejection); tri-state/null funding/insurance/value & real `verified_at`/`verified_by` | SQLite `scholarships`, `scholarship_requirements`, `scholarship_funding`, `organization_submissions`, `user_error_reports`, `verification_records`, `change_history` | Tested HTTP E2E (`catalogAccuracyAndEditorial.test.ts`, clean-dir prod smoke) |
| **Universities** (`/api/universities`) | `GET /`, `GET /:id` | Public read catalog | Missing `accreditation_status` returns `{ status: "Not specified", statusKm: "មិនបានបញ្ជាក់", isKnown: false, agency: null }` instead of fabricated accreditation | SQLite `universities`, `majors` | Tested HTTP (`catalogAccuracyAndEditorial.test.ts`) |
| **Advisor** (`/api/advisor`) | `POST /api/advisor/chat` | `optionalAuth` + CSRF for browser | When `GEMINI_API_KEY` unset -> `mode: "deterministic_offline"`, `isEstimate: true`, `unavailableData`; timeouts -> `504`; provider errors -> `503`; persists conversation ONLY if authenticated AND `canUseAIMemory` | SQLite catalog lookup + conditional `ai_conversations` | Tested HTTP (`guidanceAndPackaging.test.ts`, clean-dir prod smoke) |
| **Decision Engine** (`/api/decision`) | `POST /api/decision/evaluate` | `optionalAuth` + CSRF for browser | Explicit `mode: "rule_based"`, `isEstimate: true`, `sources`, `unavailableData`; persists telemetry ONLY if authenticated AND `canCollectAnalytics` | Rule table + conditional `activity_events` | Tested HTTP (`guidanceAndPackaging.test.ts`, clean-dir prod smoke) |
| **Operational Metrics** (`/api/metrics`) | `GET /api/metrics`, `GET /api/metrics/sqlite` | `authenticateToken` + `admin` | Admin-only exposure; live SQLite table/row counts, `verifyDatabaseHealth()`, `dbMetrics`, and HTTP p50/p95 latencies/errors | In-memory HTTP metrics + live SQLite `dbMetrics` & `sqlite_master` | Tested `401`/`403`/`200` (`guidanceAndPackaging.test.ts`) |

## 2. Extended & Post-Pilot Modules (Protected at Middleware & Consent Boundaries)

| Domain / Base Path | Disposition | Auth / RBAC Policy Applied | Consent & Isolation Notes |
| --- | --- | --- | --- |
| **Analytics** (`/api/analytics`) | Telemetry ingestion & reporting | `POST /track`, `/events`, `/game`, `/learning` require `authenticateToken`; `GET /engagement`, `/recent` require `admin` | Derives `user_id`/`student_id` from `req.user.userId`; returns `{ persisted: false, reason: 'consent_disabled' }` with 0 DB writes when `!canCollectAnalytics` |
| **AI & Memory v1** (`/api/ai`) | Post-pilot / gated | Public read-only `/knowledge*`; all student chat/recommend/insight/feedback/memory routes require `authenticateToken` + `resolveAuthorizedStudentId` | `StudentAIMemoryService.getMemory` returns empty non-persisted struct when `!canUseAIMemory` (stops Grade 12/CADT fabrication) |
| **AI OS v2** (`/api/ai-os`) | Post-pilot / gated | `GET /agents`, `GET /tutor/concept` public; student chat/memory/plans require `authenticateToken` + `resolveAuthorizedStudentId`; `/knowledge/pipeline`, `/safety/test`, `/analytics/metrics` require `admin` | Long-term memory & closed-loop analytics check `canUseAIMemory` / `canCollectAnalytics` |
| **Research** (`/api/research`) | Post-pilot / gated | `GET /experiments*` public study metadata; `POST /experiments/:id/join` requires `authenticateToken` + `canIncludeInResearch` (`403 CONSENT_REQUIRED` otherwise); `POST /experiments`, `GET /experiments/:id/report`, `GET /anonymized-dataset` require `admin` | Replaced hardcoded 8-row array with live SQLite query filtered strictly to `privacyService.getResearchEligibleStudents()` |
| **Data Platform** (`/api/data-platform`) | Mixed (Lakehouse public metadata; student & pipeline gated) | Fixed `/student-dossier/:studentId?`, `/governance/:studentId?`, `/governance/export/:studentId?`, `/ml/*` with `authenticateToken` + `resolveAuthorizedStudentId`; `/collection-matrix`, `/ai-pipeline/*` require `admin` | Removed synthetic `'Preah Sisowath...'` / `fully_consented` fallback dossier; governance status reads strictly from `PrivacyService`; flywheel writes require `canCollectAnalytics` |
| **Student Intelligence** (`/api/student/profile`) | Post-pilot / gated | `authenticateToken` + `resolveAuthorizedStudentId` on `/intelligence*`, `/recalculate`, `/ai-context` | Prevents unauthenticated or cross-student intelligence profiling |
| **Learning & STEM Labs** (`/api/learning`) | Post-pilot / gated | Catalog (`GET /subjects`, `/content*`) public; all labs, activities, paths, AI-profile, and `/analytics/event` require `authenticateToken` + `resolveAuthorizedStudentId` | Viewing logs & `/analytics/event` check `canCollectAnalytics` |
| **Learning Science** (`/api/learning-science`) | Post-pilot / gated | Mastery/ZPD/misconceptions require `authenticateToken` + `resolveAuthorizedStudentId`; `/education-report`, `/teacher-intelligence*`, `/telemetry` require `admin` | Research telemetry gated by `canCollectAnalytics` |
| **Avatar World** (`/api/avatar-world`) | Post-pilot / gated | All routes require `authenticateToken`; student derived strictly from `req.user.userId` | Visit/click/view/time-spent telemetry gated by `canCollectAnalytics` |
| **Community & Mentoring** (`/api/community`) | Post-pilot / gated | Public read directories (`/communities*`, `/posts*`, `/mentors*`, `/projects*`, `/events`, `/organizations`); all writes & `/student/:id/communities`, `/students/:id/*`, `/ai-recommendations` require `authenticateToken` + `resolveAuthorizedStudentId`; `GET /moderation/reports` requires `admin` | Activity logs gated by `canCollectAnalytics` |
| **Knowledge / Digital World / Platform** (`/api/knowledge`, `/api/digital-world`, `/api/platform`) | Post-pilot / gated | Writes & companion chat require `authenticateToken`; verify/rag-sync/audit-logs/notifications/ecosystem/monitoring require `admin` | Game telemetry gated by `canCollectAnalytics` |
